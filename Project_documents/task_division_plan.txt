2. Write PDDL Domain File (domain.pddl)
   - Define predicates:
     * (on ?x ?y)         - block x is on block y
     * (ontable ?x)       - block x is on the table
     * (clear ?x)         - nothing is on top of block x
     * (holding ?x)       - robot is holding block x
     * (handempty)        - robot gripper is empty

   - Define actions with preconditions and effects:
     * PICK-UP(?block)
       Precondition: (clear ?block), (ontable ?block), (handempty)
       Effect: (holding ?block), NOT (ontable ?block), NOT (handempty)

     * PUT-DOWN(?block)
       Precondition: (holding ?block)
       Effect: (ontable ?block), (clear ?block), (handempty), NOT (holding ?block)

     * STACK(?top, ?bottom)
       Precondition: (holding ?top), (clear ?bottom)
       Effect: (on ?top ?bottom), (clear ?top), (handempty), NOT (holding ?top), NOT (clear ?bottom)

     * UNSTACK(?top, ?bottom)
       Precondition: (on ?top ?bottom), (clear ?top), (handempty)
       Effect: (holding ?top), (clear ?bottom), NOT (on ?top ?bottom), NOT (handempty)

2. Spatial Relationship Detection

   a) is_on_table(block_pos, table_height=0.0, threshold=0.03)
      - Check if block Z-coordinate ≈ table height (within threshold)
      - Account for block half-height (0.02m for 0.04m cube)
      - Return: Boolean

   b) is_on(block_a_pos, block_b_pos, xy_threshold=0.015, z_threshold=0.005)
      - Check if block_a is directly above block_b
      - XY distance < xy_threshold (centered)
      - Z distance ≈ block_height (0.04m) within z_threshold
      - Return: Boolean

   c) is_clear(block_name, all_block_positions)
      - Check if any other block is on top of this block
      - Iterate through all other blocks, use is_on()
      - Return: Boolean

   d) is_holding(block_name, gripper_pos, block_pos, threshold=0.05)
      - Check if gripper position matches block position
      - Check gripper state (closed)
      - Return: Boolean

   e) is_handempty(robot)
      - Check gripper state
      - Verify no block is in holding position
      - Return: Boolean

2. Implement pick_up(robot, scene, block_name, blocks_state)

   Step-by-step breakdown:

   a) Get block position
      block = blocks_state[block_name]
      block_pos = block.get_pos()

   b) Compute grasp pose
      - Target: center of block
      - Orientation: gripper pointing down (quat = [0, 1, 0, 0])
      - Grasp height: block_pos[2] (center of 4cm cube)

   c) Compute pre-grasp pose
      - Same XY as grasp
      - Z offset: +0.10m above grasp (10cm clearance)

   d) Open gripper
      - Current qpos
      - Set last 2 joints to 0.04 (fully open)
      - Control to this position

   e) Plan and execute path to pre-grasp
      - Use robot.inverse_kinematics() to get target qpos
      - Use planner.plan_path(qpos_goal=target)
      - Execute waypoints with robot.control_dofs_position()
      - Step scene after each waypoint

   f) Move to grasp position (linear approach)
      - Can use planning or direct control
      - Ensure smooth approach

   g) Close gripper
      - Set gripper joints to 0.01 (grasping 4cm block)
      - Wait for gripper to close
      - Step scene multiple times for physics

   h) Lift block
      - Compute lift pose: current XY, Z + 0.15m
      - Plan and execute path upward
      - Verify block is attached (check block position follows gripper)

   i) Return to safe pose
      - Move to neutral position above workspace

3. Implement put_down(robot, scene, block_name, target_pos)

   Step-by-step breakdown:

   a) Validate target position
      - Ensure target_pos is on table (reachable, no collision)
      - Check no other block is at target

   b) Compute place pose
      - Position: target_pos (Z should be table height + half block)
      - Orientation: gripper pointing down

   c) Compute pre-place pose
      - Above target_pos by 0.10m

   d) Plan and execute to pre-place
      - Use IK + path planning
      - attached_object parameter = block being held

   e) Lower to place position
      - Linear motion downward
      - Slow approach for stability

   f) Open gripper
      - Release block
      - Step scene, let physics settle

   g) Retreat upward
      - Move up 0.10m
      - Return to safe position

   def run_tamp(scene, robot, blocks_state, goal_predicates):
       """
       Main TAMP execution loop
       """
       max_iterations = 50  # Prevent infinite loops
       iteration = 0

       while iteration < max_iterations:
           # STEP 1: Abstract current state
           current_predicates = abstract_state(scene, robot, blocks_state)
           print(f"Iteration {iteration}: Current state abstracted")
           visualize_predicates(current_predicates)

           # STEP 2: Check goal achievement
           if goal_achieved(current_predicates, goal_predicates):
               print("GOAL ACHIEVED!")
               return True

           # STEP 3: Get task plan
           action_plan = get_task_plan(current_predicates, goal_predicates)

           if not action_plan:
               print("ERROR: Task planner found no solution")
               return False

           print(f"Task plan: {action_plan}")

           # STEP 4: Execute first action from plan
           action = action_plan[0]
           success = execute_action(robot, scene, blocks_state, action)

           # STEP 5: Wait for physics to settle
           wait_for_physics(scene, steps=100)

           # STEP 6: Re-plan if execution failed
           if not success:
               print(f"Action {action} failed, re-planning...")

           iteration += 1

       print("ERROR: Max iterations reached without achieving goal")
       return False

5. Implement execute_action(robot, scene, blocks_state, action)

   def execute_action(robot, scene, blocks_state, action):
       """
       Map high-level action to motion primitive
       """
       action_name = action[0]

       if action_name == "pick-up":
           block = action[1]
           return pick_up(robot, scene, block, blocks_state)

       elif action_name == "put-down":
           block = action[1]
           # Choose safe table position
           target_pos = find_empty_table_position(scene, blocks_state)
           return put_down(robot, scene, block, target_pos)

       elif action_name == "stack":
           block_top = action[1]
           block_bottom = action[2]
           return stack(robot, scene, block_top, block_bottom, blocks_state)

       elif action_name == "unstack":
           block_top = action[1]
           block_bottom = action[2]
           return unstack(robot, scene, block_top, block_bottom, blocks_state)

       else:
           print(f"ERROR: Unknown action {action_name}")
           return False

INTERFACE SPECIFICATIONS
================================================================================

PERSON 2 → PERSON 1: State Abstraction Output
----------------------------------------------
Function: abstract_state(scene, robot, blocks_state) -> Set[Tuple]

Output Format: Set of tuples representing true predicates

Example:
{
    ("ontable", "r"),      # Red block on table
    ("ontable", "b"),      # Blue block on table
    ("on", "g", "r"),      # Green block on top of red block
    ("clear", "b"),        # Blue block has nothing on top
    ("clear", "g"),        # Green block has nothing on top
    ("handempty",)         # Robot not holding anything
}

Note: Only include predicates that are TRUE. False predicates are implicit.


PERSON 1 → PERSON 4: Task Plan Output
--------------------------------------
Function: get_task_plan(current_predicates, goal_predicates) -> List[Tuple]

Output Format: List of action tuples (ordered sequence)

Example:
[
    ("pick-up", "g"),      # Pick up green block
    ("put-down", "g"),     # Put green block on table (to clear red)
    ("pick-up", "r"),      # Pick up red block
    ("stack", "r", "b"),   # Stack red on blue
    ("pick-up", "g"),      # Pick up green block again
    ("stack", "g", "r")    # Stack green on red
]

Return None or empty list if no plan found.


PERSON 3 & PERSON 4 → PERSON 4: Motion Primitive Interfaces
------------------------------------------------------------

Function: pick_up(robot, scene, block_name, blocks_state) -> bool
  Input:
    - robot: RobotAdapter instance
    - scene: Genesis scene
    - block_name: String ("r", "g", "b", "y", "m", "c")
    - blocks_state: Dict mapping names to block entities
  Output:
    - True if successful, False if failed
  Precondition:
    - block_name must be on table and clear
    - Robot gripper must be empty
  Postcondition:
    - Robot is holding block_name
    - Block is lifted above workspace

Function: put_down(robot, scene, block_name, target_pos) -> bool
  Input:
    - robot: RobotAdapter instance
    - scene: Genesis scene
    - block_name: String (block currently being held)
    - target_pos: [x, y, z] position on table
  Output:
    - True if successful, False if failed
  Precondition:
    - Robot must be holding block_name
  Postcondition:
    - Block is on table at target_pos
    - Robot gripper is empty

Function: stack(robot, scene, block_top, block_bottom, blocks_state) -> bool
  Input:
    - robot: RobotAdapter instance
    - scene: Genesis scene
    - block_top: String (block being held)
    - block_bottom: String (target block)
    - blocks_state: Dict mapping names to block entities
  Output:
    - True if successful, False if failed
  Precondition:
    - Robot must be holding block_top
    - block_bottom must be clear
  Postcondition:
    - block_top is on block_bottom
    - Robot gripper is empty

Function: unstack(robot, scene, block_top, block_bottom, blocks_state) -> bool
  Input:
    - robot: RobotAdapter instance
    - scene: Genesis scene
    - block_top: String (top block to remove)
    - block_bottom: String (bottom block)
    - blocks_state: Dict mapping names to block entities
  Output:
    - True if successful, False if failed
  Precondition:
    - block_top must be on block_bottom
    - block_top must be clear
    - Robot gripper must be empty
  Postcondition:
    - Robot is holding block_top
    - block_bottom is clear
